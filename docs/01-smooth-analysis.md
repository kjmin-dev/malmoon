# Smooth 분석

> 기준일 2026-11-12. 공개 자료(웹사이트, 약관과 방침, 스토어 페이지, 창업자 게시물)만으로 작성했다.
> Smooth에 가입하거나 앱을 실행해 보지는 않았다.

## 한눈에

- **무엇인가.** 비원어민을 위한 실시간 영어 회의 보조 앱이다. 운영사는 Frictionless AI, Inc.이고 2026년 2월에 출시했다.
- **어떻게 동작하나.** 데스크톱 앱이 시스템 오디오를 듣고 회의 창 위에 반투명 패널을 띄운다. 회의에 봇이 들어가지 않는다.
- **얼마나 컸나.** 창업자 발표로는 사용자 1.7만 명, 유료 고객 1,700명, ARR 약 30만 달러다. 출시 8개월 시점이고 독립적으로 검증된 수치는 아니다.
- **무엇이 강점인가.** 자체 모델이 아니라 속도, 그리고 준비에서 회의, 학습까지 이어지는 흐름이다.

## 제품 구조

기능은 여덟 층으로 쌓여 있다. 층의 순서는 비원어민이 겪는 불안의 순서와 같다.
못 알아듣는다, 대답을 못 한다, 말 자체가 안 나온다, 다음에는 더 잘하고 싶다.

| 층 | 기능 | 확인된 내용 | 요금제 |
| --- | --- | --- | --- |
| 1. 캡처 | 시스템 오디오와 마이크 청취, 반투명 오버레이 | 봇 없이 Zoom, Meet, Teams, Discord, YouTube에서 동작한다. iOS와 Android 앱은 대면 회의를 다룬다. | 전체 |
| 2. 사전 준비 | 캘린더 연동 준비 화면 | 일정에서 발언 포인트, 유용한 표현, 참석자 맞춤 스크립트를 만든다. Gmail, Drive, 올린 파일을 맥락으로 쓴다. | 미확인 |
| 3. 실시간 이해 | 번역 자막, 현재 주제, 지금까지의 결정 요약 | 지연 약 200ms를 내세운다. 번역 언어 11개. 영어로 진행되는 회의만 지원한다. | 전체 (분 한도) |
| 4. 실시간 발화 지원 | 답변 카드, 의도 칩, 질문과 번역 입력창 | 질문이 끝나기 전에 답변 카드가 뜬다. 칩은 동의, 반대, 확인, 질문 네 가지다. 제안에는 근거가 된 메일이나 파일이 표시된다. | 전체 |
| 5. 음성 대리 | AI 음성 통역 | 한국어로 말하면 본인 복제 음성의 영어로 나간다. 한, 일, 중, 스페인어에서 영어 방향만 된다. | Voice Pro |
| 6. 사후 산출물 | 요약, 이중 언어 대화록, 미팅 노트 | 결정 사항, 담당자가 붙은 액션 아이템, 남은 논의를 정리한다. | 전체 |
| 7. 학습 루프 | 문장별 코칭, 표현 배우기, 피드백 리포트 | 내 발화를 자연스러운 표현으로 고쳐 준다. 표현에는 CEFR 등급이 붙고 회의마다 점수와 발언 비중이 나온다. | 전체 |
| 8. 팀 | 팀 메모리, 고유 용어, 노트 공유 | 용어는 500개까지 등록한다. 역할은 관리자, 작성자, 멤버 세 가지다. | Team (5인 이상) |

## 기술 구성

Smooth는 자체 모델 없이 외부 음성 모델과 언어 모델을 조합한다. 아래는 Smooth가 직접 공개한 내용이다.

| 구성 | 내용 | 출처 |
| --- | --- | --- |
| 클라이언트 | macOS, Windows 데스크톱 앱과 iOS, Android 앱 | 다운로드 페이지, 스토어 |
| 캡처 | 시스템 오디오와 마이크. 회의 봇 없음 | FAQ |
| 음성 인식 | Deepgram | 개인정보처리방침 |
| 언어 모델 | OpenAI, Anthropic, Groq, Google Vertex AI | 개인정보처리방침 |
| 음성 복제 | Fish Audio | 생체정보 방침 |
| 저장 | Google Cloud. 음성은 저장하지 않는다고 밝힌다 | 개인정보처리방침 |
| 결제 | Polar | 개인정보처리방침 |
| 연동 | Google 캘린더, Gmail, Drive (읽기 전용) | 개인정보처리방침 |

기획에 주는 의미는 세 가지다.

- **진입 장벽은 모델이 아니다.** 모든 부품이 구매할 수 있는 API다. 같은 수준의 경험은 재현할 수 있고, 승부는 지연 튜닝과 제품 설계에서 난다.
- **음성과 대화록이 여러 회사를 거친다.** 회사 보안 심사에서 약점이 되는 지점이다.
- **화면 공유에서 숨겨지지 않는다.** FAQ가 화면을 공유하면 앱이 보일 수 있다고 인정한다.

## 강점: 우리가 맞춰야 할 기준

| 강점 | 근거 | 맞춰야 할 기준 |
| --- | --- | --- |
| 속도 | 번역 자막 지연 약 200ms를 내세운다. 창업자는 2초만 지나도 의미 없는 정보가 된다고 썼다. | 자막과 답변 카드의 체감 지연에서 뒤지지 않을 것 |
| 설치만 하면 되는 캡처 | 봇 초대, 주최자 권한, 플랫폼별 설정이 필요 없다. | 첫 실행 후 1분 안에 자막이 나올 것 |
| 준비에서 학습까지의 흐름 | 준비, 실시간 프롬프터, 요약, 코칭이 한 앱에서 이어진다. | 준비, 회의 중, 회의 후 세 구간을 모두 갖출 것 |
| 내 맥락에 근거한 제안 | 메일, 문서, 팀 메모리를 근거로 답변을 제안하고 출처를 보여준다. | 제안마다 근거를 표시할 것 |
| 낮은 가격 | 카드 없이 200분 무료, 무제한 요금제가 월 $18.3다. | 무료 구간에서 핵심 기능을 모두 경험하게 할 것 |
| 빠른 개선 주기 | 2026년 7월 말부터 한 달 동안 릴리스 노트가 여덟 번 올라왔다. | 주 단위 배포와 사용자 직접 채널을 운영할 것 |

## 확인된 제약

- 영어로 진행되는 회의만 번역한다. 스토어 설명이 다른 언어 회의는 지원하지 않는다고 밝힌다.
- 음성 통역은 영어 방향으로만 된다.
- 화면을 공유하면 오버레이가 상대에게 보일 수 있다.
- 전화 통화는 전사하지 않는다.
- 녹음과 전사에 대한 동의 책임은 약관상 사용자에게 있다.
- Team 플랜은 5인 이상부터이고 가격, SSO, 감사 로그는 공개돼 있지 않다.

## 조사 한계

- Smooth에 대한 독립적인 사용자 후기는 찾지 못했다. 긱뉴스, 디스콰이엇, Threads에는 창업자 게시물뿐이었다.
- 약 200ms라는 지연 주장은 측정하지 않았다.
- 성장 수치는 창업자 게시물을 인용한 2차 자료에서 왔다.
